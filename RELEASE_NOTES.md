## Toggle marks and close the Schedule menu

Choosing **Mark as interested** or **Mark not interested** twice clears the mark and restores the default appearance; choosing the other state switches it. Applies in Search, Discover, Schedule, and anime-page menus, with undo and saved marks preserved.

Discover → Schedule now uses its **right-click menu** (alongside Preview and Open page), not buttons on rows. Green borders/badges, negative fading/hiding, and shared AniList-series marks work for all episodes.

## Permission and updates

Seanime requires approval for the additional `dom-script-manipulation` permission used solely to dismiss Schedule menus through native Escape handling. This disables automatic updates, so replace the extension JSON manually to update it. **Keep the existing extension ID and do not uninstall** if you want to retain your saved marks. The plugin needs Storage permission, and makes no network requests or file access.
